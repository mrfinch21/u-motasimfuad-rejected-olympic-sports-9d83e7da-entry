A program that writes one line to `/output/entry.txt` for make.fun's "Rejected Olympic Sports" bounty: one funny single-line sport the Olympics turned down, written the way a broadcaster would announce it.

> Competitive Apologising: athletes apologise for winning, for losing, and for apologising — gold goes to whoever means it least.

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (127 characters, inside the 1–200 gate), validates the gate before writing, and reads the file back to verify it landed byte-identical.
